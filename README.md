# PRODiGY_GA_01 – Text Generation with GPT-2

## Overview
This project demonstrates text generation using the GPT-2 language model. GPT-2 is a transformer-based model capable of generating coherent and context-aware text from a user-provided prompt.

## Objective
- Understand the working of the GPT-2 language model.
- Generate meaningful text from custom prompts.
- Explore transformer-based text generation techniques.
- Gain practical experience with Generative AI.

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- PyTorch
- GPT-2

## Project Workflow
1. Install the required libraries.
2. Import the necessary Python modules.
3. Load the GPT-2 model and tokenizer.
4. Enter a custom text prompt.
5. Generate text using the GPT-2 model.
6. Display and evaluate the generated output.

## Results
The GPT-2 model successfully generated context-aware text based on the given prompt. The generated output demonstrated the capability of transformer-based language models to produce fluent and meaningful text.
