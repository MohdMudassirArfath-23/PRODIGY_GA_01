# PRODIGY_GA_01

## Project Title
Text Generation with GPT-2

## Overview
This project demonstrates text generation using the GPT-2 pre-trained language model. The model generates coherent and contextually relevant text based on user prompts.

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- PyTorch
- GPT-2

## Features
- Generates text from custom prompts
- Uses a pre-trained GPT-2 model
- Simple and beginner-friendly implementation

## Project Outcome
Successfully generated meaningful text using the GPT-2 pre-trained language model.
